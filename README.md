# odin-recipes
Restarting my journey in full stack development by doing lessons
through The Odin Project :)

In this project I will showcase some of my favorite recipes I have made
in the past. Feel free to take some of these and try them yourself! 

Fundamental skills used in this project: document structure, semantic markup, media embedding, hyperlinking and content organization.
Upon the completion of this project, I noticed I remembered a lot of the basic HTML structure which made it easy for me to build this in no time. It honestly made me excited to dive deeper and take my journey into programming more seriously.

Happy cooking (and coding)!
